# Commit Guide

Use this format:

```text
<type>: <imperative summary>
```

Good examples:

- `feat: add stock movement service`
- `feat: send low-stock SMS alerts`
- `fix: prevent duplicate threshold notifications`
- `docs: document USSD callback flow`
- `test: cover stock threshold transitions`

Avoid vague subjects such as `updates`, `changes`, `work`, `final`, `stuff`, `fix bugs`, or `codex changes`. Each commit must contain one coherent concern and must not include AI attribution.
