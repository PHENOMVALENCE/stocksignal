# Design Direction

StockSignal should communicate manufacturing, operations, monitoring, reliability, and urgency only when action is needed.

- Use a restrained neutral palette with one strong brand accent.
- Reserve green, amber, and red for consistent inventory status semantics.
- Make quantities and units visually prominent.
- Prefer dense, readable tables and responsive layouts.
- Maintain accessible contrast and visible focus states.
- Design explicit loading, error, and empty states.

Avoid excessive gradients, glassmorphism, large hero animations, decorative 3D, random glowing effects, unnecessary dashboard cards, heavy shadows, and a generic generated SaaS appearance. Operational clarity comes first.
